# SAR2Action Phase 4 — real agent validation

Validated on Windows, 2026-11-12. **Real AI Analysis** means a local LLM chooses allowlisted GIS tools. All completed measurements in this report use **SIMULATED DATA — NOT NASA OBSERVATIONS**. No real NISAR handoff was present.

| NISAR live data | **BLOCKED**: `SAR2ACTION_SPATIAL_MANIFEST` absent; live mode refuses synthetic substitution. |

The [official Hermes releases](https://github.com/nousresearch/hermes-agent/releases) listed v0.23.1 as the newest stable version checked. The available Python package index exposed only v0.19.0, so the isolated installation was retained. Its doctor check passed. The [Hermes API server documentation](https://hermes-agent.nousresearch.com/docs/user-guide/features/api-server) and [tools documentation](https://hermes-agent.nousresearch.com/docs/user-guide/features/tools/) describe broad default capabilities. Our `.phase4_hermes/config.yaml` sets `platform_toolsets.api_server: []`; `scripts/check_hermes_profile.py` verifies that the resolved gateway toolset is empty. Hermes and model server both listen on localhost. The model server is never exposed to the browser.

The RTX 5070 Ti has 16,303 MiB reported VRAM. `nvidia-smi` after browser and agent runs reported 15,879 MiB used, 117 MiB free; memory measurements vary with other processes. `/props` reported `n_ctx=4096`. This is near the VRAM limit and provides no basis to claim a 64K local Hermes run. A direct model probe with 400 output tokens stopped at the length limit before completing a call; 800 tokens completed a function call. The agent uses the latter limit and at most three selection rounds.

## Real model investigation and safety

The real model selected `rank_change_regions`, then `compare_regions` and `inspect_evidence` for the requested Chinese three-region comparison. The complete sanitized event list is in [phase4_real_agent_trace.json](phase4_real_agent_trace.json). It records the question, selected intents, validated arguments, tool status, Evidence IDs, map actions, final response and 11,941.6 ms duration. It does not include hidden reasoning or credentials. The trace contains three model-selected `inspect_evidence` calls; the executor de-duplicates the tool, so one inspection ran. The UI can inspect each region separately. The explanatory narrative is generated by the deterministic science service from its evidence; the real model plans tool calls but does not freely write scientific measurements.

`real_agent_runtime.py` accepts only advertised, JSON Schema-checked tool calls. Trusted case, AOI, evidence IDs and map geometry come from the application and science tools. It rejects unknown tools, changed case/AOI, stale Evidence IDs and unregistered map actions. No model-produced Python, JavaScript or shell is executed. Tool selection has bounded retries. Cancel is cooperative between model/tool calls; an in-flight model HTTP request or raster operation is not interrupted immediately. The UI aborts its request and sends server cancel.

The user chooses **Deterministic Demo** or **Real AI Analysis** separately from **Synthetic Demo** or **Live NISAR** data. The panel shows model connectivity, operation progress, ranked cards, map focus, fingerprint, clickable Evidence, five-scene story, public/scientific modes, cancel/retry and stale status. The real-model Chrome run confirmed MapLibre focus, three regions, comparison, evidence and story. Screenshot: [real-agent-flow.png](../frontend/test-results/agent-spatial-flow-real-lo-c7aba-e-GIS-tools-through-FastAPI-chrome/real-agent-flow.png). It displays synthetic data explicitly.

## NISAR handoff

`scripts/validate_nisar_handoff.py` checks schema/data kind, pair metadata, ordered timestamps, polarization, hashes, registered parent Evidence, contained paths, aligned EPSG:4326 georeferenced single-band GeoTIFFs, float dB change, mask and NoData behavior. Run it with `SAR2ACTION_SPATIAL_MANIFEST` pointing to the B-team JSON manifest. The [current report](phase4_nisar_handoff_report.json) states precisely that this environment has no manifest. Region geometry and fingerprints are produced by the existing spatial ranking and science services after valid input; this validator tests their raster input contract. Its declared NoData requirement is stricter than the current live adapter and should be agreed with B team before handoff. No NASA observation was fabricated.

## Start and repeat the demo

From `D:\SAR2Action` in PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\run_phase4_demo.ps1
```

Open `http://127.0.0.1:5173`, select **Synthetic Demo** data and **Real AI Analysis** execution, choose the AOI, and ask: `找出目前選取範圍中變化最大的三個區域，比較它們，帶我查看證據。` Then focus a ranked card, view its fingerprint and Evidence, and generate a Story. The script checks/starts the existing local llama.cpp model, restricts the Hermes gateway, starts the backend and Vite, and checks service health. It uses the already present executable and GGUF at their machine-specific paths; another Windows machine must update those two paths and install matching dependencies. To stop only launcher-owned services:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\run_phase4_demo.ps1 -Stop
```

For the offline fallback, run `scripts\run_phase3_demo.ps1` and select **Synthetic Demo** plus **Deterministic Demo**. For live mode, provide a validated B-team manifest and real scene data first. The application never silently switches live requests to synthetic data.

## Remaining blockers

1. Hermes chat inference and Hermes-mediated tool calling remain blocked by its 64K minimum context versus the local server's measured 4,096 context. The direct llama.cpp tool-calling route is operational and restricted.
2. B-team NISAR handoff is absent, so measurements and evidence in the demo are synthetic. Real scientific validation remains pending.
3. The 24-question benchmark is a single-model, single-fixture run. It does not establish reliability across real scenes, models, concurrent users or arbitrary prompts. Session and cancellation state are in process memory.
