## 二、輻射校正與幾何解析度 QA

1. **PB `05.13` BOA Offset 檢核（避免假負值）**：
   - Element84 STAC 屬性明確設定 `earthsearch:boa_offset_applied = true`（雖 `raster:bands` 仍遺留 `offset: -0.1` 靜態宣告，實際 GeoTIFF COG 像元已先減除 `1000`）。
   - 於 `2026-10-11` `SCL = 4` 植被像元抽檢實測：`B04` 原始 `uint16` DN 中位數為 `670.0`、`B08` 為 `3115.0`；直接依 `uint16_dn * 0.0001` 換算所得中位 NDVI = `0.6440`（物理合理）；若誤套雙重 `-0.1` offset 會造成 `89.8%` `B04` 像元變成負反射率、NDVI 暴衝至 `1.3288`。因此全部管線固定使用 `reflectance = uint16_dn * 0.0001`。
2. **原生雙解析度整數網格**：
   - 嚴格保留 Sentinel-2 原生空間解析度不強制重採樣：
     - **10 m (`510 × 512`, `EPSG:32651`)**：`B02, B03, B04, B08` → `NDVI = (B08 - B04) / (B08 + B04)`
     - **20 m (`255 × 256`, `EPSG:32651`)**：`B05, B8A, B11, B12, SCL` → `NDRE = (B8A - B05) / (B8A + B05)`、`LSWI = (B8A - B11) / (B8A + B11)`
   - 裁切視窗 `[222140.0, 2622180.0, 227260.0, 2627280.0]` 與 `51QTG` 20 m 原點 `(199980, 2700000)` 精確對齊整數倍，消除 0.5 像元偏差並完整涵蓋 TW-01 AOI。

### 3. 181 候選坵塊 vs 同面積級其他農田 (`>= 0.16 ha`, `n = 3,418`) 光譜時序比較（僅限雙期清晰交集：`119` vs `2,313` 筆）

  - 181 候選中位數 **`-0.0052`**（平均 `-0.0241`，標準差 **`0.2526`**，P10 `-0.4230` 至 P90 `+0.2699`）；其他同面積農田中位數 **`-0.0682`**（平均 `-0.0655`，標準差 **`0.1731`**，P10 `-0.2512` 至 P90 `+0.1357`）。
  - Mann-Whitney U 檢定 `p = 0.001486`、Kolmogorov-Smirnov `KS = 0.2273 (p = 1.279e-05)`。
  - **雙向大幅變動比例顯著較高**：候選組發生雙向顯著變化 `|ΔNDVI| >= 0.15` 比例達 **`47.06%`**，顯著高於同面積對照農田的 **`33.16%`**；但單純負向下降 `ΔNDVI <= -0.15` 比例為 `22.69%` vs `24.12%`（整體幾乎無差異），原因是 181 候選組同時混合了正負兩端變化（高變異雙峰現象，如診斷圖 C 所見）。
- **181 候選組內之 SAR (`10/14 → 10/26`) 與 Sentinel-2 (`10/11 → 11/05`) 共變關係**：
  - 有符號相關性（Spearman ρ，n = 119 筆 NDVI / 120 筆 NDRE, LSWI）：
    - `SAR ΔVH` vs `ΔNDVI`: **`ρ = +0.2786` (`p = 0.002159`)**；`SAR ΔVV` vs `ΔNDVI`: **`ρ = +0.2293` (`p = 0.01214`)**
    - `SAR ΔVH` vs `ΔNDRE`: **`ρ = +0.2821` (`p = 0.001802`)**；`SAR ΔVV` vs `ΔNDRE`: **`ρ = +0.2081` (`p = 0.02259`)**
    - `SAR ΔVH` vs `ΔLSWI`: **`ρ = +0.2686` (`p = 0.003017`)**；`SAR ΔVV` vs `ΔLSWI`: **`ρ = +0.2006` (`p = 0.02804`)**
    - 若不區分正負符號只看絕對幅度 `max(|ΔVV|, |ΔVH|)` vs `|ΔNDVI|`：`ρ = -0.0146` (`p = 0.8745`，無單調相關)。
  - **依有符號 SAR 變化方向拆分子群（關鍵物理洞見）**：
    - **`ΔVH <= -3 dB` 子群**（19 筆中 12 筆雙期清晰）：`ΔNDVI` 中位數 **`-0.2812`**（平均 `-0.2699`）、**`66.67%`** 出現 `ΔNDVI <= -0.15`；`ΔNDRE` 中位數 **`-0.2130`**；`ΔLSWI` 中位數 **`-0.1616`**（植被冠層／含水量與體散射同步明顯下降）。
    - **`ΔVV <= -3 dB` 子群**（33 筆中 23 筆清晰）：`ΔNDVI` 中位數 `-0.0548`（平均 `-0.1018`），`34.78%` 出現 `ΔNDVI <= -0.15`。
    - **`ΔVH >= +3 dB` 子群**（107 筆中 74 筆清晰）與 **`ΔVV >= +3 dB` 子群**（62 筆中 34 筆清晰）：`ΔNDVI` 中位數反呈小幅正值（`+0.0369` 與 `+0.0521`），僅 `17.57%` / `11.76%` 出現 `NDVI` 明顯下降。
    - 這證明 TW-01 以 `|ΔdB|` 篩出的 181 筆候選包含**截然不同的物理變化方向**（可能同時對應秋收翻耕、再生長或作物物候轉換），若未拆開方向且無作物真值標籤，絕不應等同於「已確認農損」。

## 五、五項可行性問題實證結論（回答清單）

1. **四個目標日期中，哪些日期實際可用？各日雲/雲影占比多少？**
   - 僅 **`2026-10-11`**（AOI 清晰 **`97.57%`**，雲/雲影 **`0.00%`**，`USABLE_CLEAR`）與 **`2026-11-05`**（AOI 清晰 **`79.07%`**，雲/雲影 **`15.90%`**，`USABLE_CLEAR`）兩日實際可用於全區與多坵塊分析。
   - **`2026-10-16`**（AOI 清晰僅 **`4.64%`**，薄捲雲+雲層 **`95.21%`**）與 **`2026-10-26`**（AOI 清晰僅 **`16.14%`**，雲/雲影 **`66.34%`** + 未分類 `17.52%`）在實務上皆因重度雲遮蔽判定為 `CLOUD_OBSCURED_UNUSABLE`。
   - 此外，於雙日晴空交集下，181 候選與 4,863 全農田僅約 **`65%`**（`119 / 181` 與 `3,166 / 4,863`）能同時通過兩期嚴格晴空覆蓋門檻，證實在臺灣秋冬雲霧環境下 Sentinel-2 光學資料具有高度間斷性，**無法取代 SAR 作為事件期間全時域主篩選工具，但適合晴空時段複驗與季節背景建立**。

2. **10 m / 20 m 解析度是否足夠區分雲林小農坵塊？**
   - **對雲林中位尺度農田（中位 `0.2547 ha`）足夠，對最細碎 ~5% 小坵塊於 20 m（NDRE / LSWI）偏緊**：

     - 相較 TW-01 SAR（30 m 網格門檻 `>= 5 px`），Sentinel-2 10 m 網格在空間細膩度（於 181 候選內中位 `49 px` vs SAR `5–9 px`）確實更適合解析窄條狀農田與排除道路建物邊界混合效應。

3. **NDVI / NDRE / LSWI 在現有資料下能否提供合理、穩定的農業光譜指標？**
   - **可以**，前提是必須嚴格確認 Element84 `earthsearch:boa_offset_applied = true`（僅乘 `0.0001`、不可重複減 `0.1`）並結合逐像元 `SCL {4,5,6}` 篩選。
   - 在 `2026-10-11`（AOI NDVI 中位 `0.4014`、NDRE `0.3139`、LSWI `0.1399`）與 `2026-11-05`（AOI NDVI 中位 `0.3466`、NDRE `0.2568`、LSWI `0.0716`）下，空間上農田與聚落道路（見 [s2_ndvi_ndre_lswi_timeseries_map.png](file:///D:/NASA/SAR2Action/tw08/sentinel2-demo-v1/s2_ndvi_ndre_lswi_timeseries_map.png)）紋理分明、物理值域正常且無雲影溢漏假影。

4. **181 筆 SAR 變化候選坵塊，在 Sentinel-2 上是否呈現不同的多時相光譜軌跡或分布特徵？**
